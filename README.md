# QA Project – Saucedemo Website

## Objectif
Tester les fonctionnalités principales du site Saucedemo.

## Contenu du projet
- **Test Plan** : Planification des tests avec critères d’entrée et de sortie
- **Test Cases** : 32 cas de test manuels couvrant login, panier,tri, checkout,logout
- **Bug Reports** : Rapports détaillés avec sévérité et liens vers les cas de test
- **Trello** : Organisation des tâches et suivi des tests

## Outils utilisés
- Excel (plan de test, cas de test, rapports de bugs)
- Trello (suivi de projet)

## Notes
- Tous les cas de test sont prêts pour des tests de régression
- Projet préparé dans un cadre QA manuel, adapté à un profil junior
